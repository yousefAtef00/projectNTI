# projectNTI

Backend E-commerce API built with Node.js, Express.js, and MongoDB.

## Features
- User Authentication (JWT)
- Email Confirmation
- Product CRUD
- Cart Management
- Checkout
- Orders

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
- Nodemailer

## Run

```bash
npm install
nodemon
```
